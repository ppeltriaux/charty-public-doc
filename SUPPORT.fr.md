## Foire aux questions

### Comment déverrouiller les réglages parentaux ?

L'icône en forme d'engrenage (en haut à droite de l'onglet Récompenses) ouvre le verrou parental. Déverrouillez-le avec votre code ou Face ID. Si vous n'avez pas encore défini de code, le verrou est ouvert par défaut — définissez-en un dans **Réglages → Sécurité**.

### Mon enfant ne voit pas la récompense que j'ai ajoutée.

Les récompenses sont visibles pour les enfants dans l'onglet Récompenses. Si la vôtre n'apparaît pas, vérifiez que vous l'avez enregistrée dans **Réglages → Gestion des récompenses → Gérer les récompenses**. Le coût en points peut aussi être supérieur au solde actuel — essayez de le baisser temporairement pour confirmer.

### Comment remettre le solde de points à zéro ?

**Réglages → Données → Réinitialiser le solde de points.** Une alerte centrée demande confirmation. L'historique des points gagnés n'est pas affecté.

### Puis-je partager une routine entre deux iPad / iPhone ?

Oui — activez **Réglages → Données → Synchronisation iCloud**, puis relancez Charty. Vos routines, points et progrès se synchronisent via votre propre compte iCloud sur tous vos appareils.

### Les célébrations sont trop intenses pour mon enfant aujourd'hui.

Activez **Réglages → Sensoriel → Célébrations calmes uniquement**. Chaque routine utilise alors la célébration **Onde calme** à l'intensité **Douce** jusqu'à ce que vous désactiviez l'option.

### Comment imprimer une routine ?

Ouvrez la routine dans l'onglet Créer → descendez → **Imprimer ou partager en PDF** → feuille de partage iOS → AirPrint (ou Enregistrer dans Fichiers / Mail / Messages). Les longues routines sont paginées par 8 tâches.

### Puis-je exporter mes données ?

**Réglages → Données → Exporter les sessions en CSV.** Génère un CSV des sessions terminées et des récompenses échangées que vous pouvez partager avec un thérapeute ou un ergothérapeute.

### Mon enfant a terminé un puzzle — peut-il en faire un autre ?

Oui. **Réglages → Puzzle image → Source de l'image** → touchez une scène incluse ou choisissez une photo pour démarrer un nouveau puzzle. Le puzzle terminé est archivé dans **Puzzles complétés précédents** sur la page de jeu.

### Comment changer la langue de Charty ?

**Réglages → Langue** → choisissez parmi les 7 langues prises en charge (français, anglais, espagnol, italien, allemand, portugais Brésil et Portugal) ou laissez sur « Utiliser la langue du système ». La modification prend effet à la prochaine ouverture de l'app.

### Qu'est-ce qui est gratuit, et qu'est-ce que Charty Plus ?

La version gratuite comprend **2 tableaux, jusqu'à 5 tâches par tableau et 1 enfant** — une routine complète. **Charty Plus** (achat unique, pas d'abonnement) débloque les tableaux et tâches illimités, plusieurs enfants, l'enregistrement de votre voix, le suivi parental, les minuteurs par étape, l'application Apple Watch et le widget interactif, ainsi que tous les thèmes.

### Comment débloquer Charty Plus ?

**Réglages → Charty Plus → Débloquer** (derrière le verrou parental). Vous pouvez aussi y accéder via l'invite qui apparaît lorsque vous atteignez une limite de la version gratuite.

### J'ai déjà payé Charty — dois-je payer à nouveau ?

**Non.** Si vous possédiez Charty quand c'était une app payante, Charty Plus se débloque automatiquement et gratuitement — vous n'êtes jamais invité à payer une seconde fois.

### J'ai acheté Charty Plus sur un autre appareil / après réinstallation — comment le récupérer ?

**Réglages → Charty Plus → Restaurer les achats.** C'est un achat unique lié à votre identifiant Apple, couvert par le Partage familial.

## Rapports de bug

Lorsque vous envoyez un e-mail, merci d'inclure :

- Modèle d'iPhone / iPad (ex. iPhone 15)
- Version d'iOS (Réglages → Général → Informations → Version du logiciel)
- Version de Charty (Réglages → À propos → Version)
- Ce que vous avez touché qui a déclenché le bug
- Capture d'écran si possible
